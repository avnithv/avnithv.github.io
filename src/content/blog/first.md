I've been procrastinating making my first blog post for a while, mainly because I didn't really know what I wanted to write about. In this post, I'll try to figure that out and set reasonable expectations for this.

I'll try to write something every 2 weeks or so. This could change based on when I have more or less time. I plan to write about mostly anything, including
- something interesting I learned recently
- a project that I'm working on
- updates / reflections on life
- a cool problem I solved
- etc.

I already have a few blog ideas in reserve, so I should be able to write at least the first few posts consistently. Most of my blogs will likely be short, because I don't really like writing a lot. But I think practicing writing consistently would be good for me.

Ok, that's it for now.
