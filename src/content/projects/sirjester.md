Sir Jester is a retro 2D platformer where you play as a jester running back
and forth and jumping to collect colorful gems to build a silly mosaic hat to amuse the queen. The
twist: you have to gather the exact number of gems of each color - if you overgather a
color, you'll drop them, so timing and restraint matter as much as speed. This game was designed and built on a team with 3 other friends.

## The constraint

Sir Jester was built for the AppLovin track at TartanHacks 2026 whose
challenge was to build a browser game that fits in under 15 KB
compressed. We combined this constraint with the TartanHacks theme of Mosaic. Everything is in a single HTML file - the game
loop, rendering, and music all in one place using CSS and JavaScript. To stay under budget, we drew original pixel art which was hand-optimized and encoded within the html file to meet the size constraint.
